Web Dev 101

What is web development?

Web development is the work of building the things you use inside a browser — every site you've ever visited, from a search engine to your bank, started as someone writing and connecting code.

At its core, it's the practice of turning an idea into a page that loads over the internet: something a browser can request, receive, and display. That page might be a single static screen, or it might talk to a database, check who's logged in, and change every time you load it — like this one does.

Two halves of the same site

What you see

The layout, text, buttons, and interactions rendered in your browser.

What you don't

The server logic, database, and auth that decide what you're allowed to see.

This site is a small example of that split — a login page, a database of sessions behind the scenes, and pages like this one that only render once the backend confirms you're signed in.
